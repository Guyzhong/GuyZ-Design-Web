# GuyZ.Design — IDP 后台体验设计师作品集

> 把 IDP 的复杂配置，做成顺手的秩序。

## 🎯 项目目标

这是一个面向 IDP（内部开发平台）领域的设计师个人作品集网站，核心目标是**获客与转化**：通过展示专业能力和真实案例，引导潜在客户通过微信建立联系。

## ✅ 已完成功能

### 首页 (`index.html`)
- **Hero 区**：主标题 + 副标题 + 能力标签 + 主/次 CTA
- **服务区**：3 张服务卡片（体验体检 / 关键模块改版 / 组件与规范体系）
- **案例区**：3 张案例卡片（信息架构重构 / 内容管理提效 / 权限一致性治理）
- **底部 CTA**：强调"发截图换建议"的低门槛入口
- **全局导航**：固定顶部 + 移动端汉堡菜单

### 案例详情页 (`case-1.html`, `case-2.html`, `case-3.html`)
- 统一结构模板：一句话结论 → 背景与约束 → 问题证据 → 关键取舍 → 方案展示（前后对比）→ 落地协作 → 复盘与下一步 → CTA
- 案例间导航（上一个/下一个）

### 联系页 (`contact.html`)
- 微信转化页：引导文案 + 三步流程 + 微信二维码占位 + 微信号复制功能
- 适用场景说明

### 交互 & 样式
- 深色科技风设计（暗底 + 蓝紫强调色）
- 滚动入场动画（IntersectionObserver）
- 导航滚动毛玻璃效果
- Hero 浮动卡片动画
- 全站响应式（桌面 / 平板 / 手机）
- 微信号一键复制

## 📂 文件结构

```
index.html          → 首页（Hero + 服务 + 案例 + CTA）
case-1.html         → 案例：配置页信息架构重构
case-2.html         → 案例：内容管理提效
case-3.html         → 案例：权限与状态一致性治理
contact.html        → 联系页（微信转化）
css/style.css       → 全局样式
js/main.js          → 交互逻辑
README.md           → 项目文档
```
