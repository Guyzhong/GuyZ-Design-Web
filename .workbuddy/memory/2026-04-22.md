# 2026-04-22 工作日志

## GuyZ Design-Web 移动端适配

对 `css/style.css` 的 Responsive 部分进行了全面重写，覆盖所有页面（首页、3 个案例详情页、联系页）。

### 主要变更

**断点策略调整**
- 1024px：平板态，服务/案例从 3 列改为 2 列（原来直接跳单列），Hero visual 隐藏
- 768px：移动态，全部单列，字号/间距收紧
- 480px：小屏手机，按钮全宽、QR 码缩小、更紧凑间距

**触控安全**
- 所有按钮、导航链接、微信号复制区添加 `min-height: 44px`（共 7 处）
- 汉堡菜单按钮 `min-width/min-height: 44px`

**布局优化**
- Hero：768px 以下 badge/tag 字号缩小、subtitle 0.95rem、padding 收紧
- 服务/案例：768px 单列 max-width 560px/480px、封面高度 160px→140px(480px)
- Bottom CTA：768px 以下 padding 缩小、装饰圆 400px→250px
- 案例详情：summary padding 从 xl 缩至 md、section 标题 1.2rem
- 联系页：卡片 padding lg、QR 200px→160px(768px)→140px(480px)

**iOS Safe Area**
- 新增 `@supports (padding-bottom: env(safe-area-inset-bottom))` 为 footer 和 CTA 按钮添加安全区

**主题切换按钮**
- 768px 以下 `.nav-actions` 移至 overlay 菜单底部居中，避免与汉堡按钮冲突

### 技术栈
- 纯 HTML + CSS（无 Tailwind），自定义 CSS 变量体系
